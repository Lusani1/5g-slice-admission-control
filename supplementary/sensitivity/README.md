# Sensitivity analyses

This directory contains the supplementary sensitivity material associated with the manuscript.

## Parameter sensitivity

The executable one-factor-at-a-time parameter-sensitivity analysis compares:

- Conservative admission
- Static OPF 1.75
- Static OPF 2.00

The tested levels are:

- Capacity: 80, 100, 120 units per resource
- Demand multiplier: 0.8, 1.0, 1.2
- SLA penalty multiplier: 0.5, 1.0, 2.0
- Overbooking penalty multiplier: 0.5, 1.0, 2.0

Run from the repository root:

```bash
python3 supplementary/sensitivity/run_parameter_sensitivity.py \
  --data-root /path/to/materna_synthetic_slice_profiles_forecasting_ready \
  --output-dir results/parameter_sensitivity \
  --runs 30 \
  --epochs 288 \
  --training-episodes 120
```

The runner writes raw per-seed results, confidence-interval summaries, paired tests, SLA-feasible rankings, plots, and LaTeX tables under the selected output directory.

`manuscript_figures/parameter_sensitivity_analysis.png` is the parameter-sensitivity figure included in the manuscript.

## Forecast-mode sensitivity figures

The files

- `manuscript_figures/fig_static_opf_forecast_mode_sla.png`
- `manuscript_figures/fig_static_opf_forecast_mode_reward.png`

are the forecast-mode sensitivity figures included in the manuscript. They belong to a separate diagnostic sweep comparing no-forecast, synthetic forecast, and XGBoost forecast modes. They are retained here for direct correspondence with the submitted article and are not generated by `run_parameter_sensitivity.py`.

The verified 30-run admission-control reference results remain under `results/reference_run/` and are independently checked by `scripts/verify_reference_results.py`.
