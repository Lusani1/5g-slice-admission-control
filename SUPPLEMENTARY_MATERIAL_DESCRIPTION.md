# Supplementary material description

## Reproducibility repository

Source code, experiment configuration, implementation tests, compact 30-run reference results, statistical summaries, result-verification utilities, figure-generation utilities, data fingerprints, and supplementary parameter-sensitivity code associated with the manuscript *SLA-Aware Resource Overbooking for 5G Core Network Slicing Using Forecasting-Assisted Admission Control*.

## Full run evidence

Complete decision-level and epoch-level outputs from the 30 paired Monte Carlo runs, together with the experiment configuration, processed-data fingerprints, and SHA-256 manifest.
